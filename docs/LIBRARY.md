# Acuity Open Library

A working first phase of the Archive, at `/library/`. The collection is open to visitors without an account. PDF.js is loaded only when a reader opens a PDF; books, workers, font data and decoders are served on the same origin. EPUB files download for an e-reader; there is no in-browser EPUB renderer in this phase.

## Included experience

- Responsive charcoal/gold styling, Cormorant Garamond headings, Inter body and monospaced labels consistent with the landing page.
- Search titles, authors, translators and subjects; combine collection and format filters; sort by title.
- Shareable book details: `/library/?book=meditations`.
- PDF reader with page navigation, direct page entry, fit/zoom, accessible text mode, download, loading and failure states, and keyboard-dismissable native dialogs.
- Full PDF, EPUB and plain-text files, edition notes, source links and file hashes.
- Crawlable library HTML and structured Book/CollectionPage metadata generated at build time.
- Existing webinars and shorts are retained. The home navigation, hero and Archive card now point to the library.

## Run and deploy

Use Node 22.13+ (the `.nvmrc` selects Node 22). The pinned PDF.js dependency requires this runtime for tooling.

```sh
npm ci
npm run typecheck
npm run build
npm test
npm start
```

Railway can keep its existing `npm run build` / `npm start` commands and `PORT`. `/health` and the existing `SHORTS_DIR` volume route are retained. No new database, secrets or subscriptions are required. The PDFs/EPUBs are packaged in the build and survive redeployment.

`npm run dev` is useful for component work. Production metadata and directory routes are generated by `npm run build`; test them with `npm start`.

## Add a book

1. Choose an edition you have permission to distribute, retaining attribution and licence notices. Record its translator and edition, rather than assuming that an ancient original makes every modern translation unrestricted.
2. Add its PDF and/or EPUB to `public/library/books/`, using a lowercase hyphenated filename. Optional `.txt` supports accessible full-text reading.
3. Add a record to `src/data/libraryCatalogue.json`. Copy an existing entry and supply a unique stable `id`, title, author, optional translator, collection, period, language, description, edition note, subject tags, source URL, rights statement and local file paths. Omit formats that do not exist. `accent` is `gold`, `sage` or `violet`. Supply the PDF page count when available. `sourceId` is only for a Project Gutenberg source.
4. Run `npm run catalogue:sync` to record file sizes and SHA-256 hashes in `public/library/provenance.json`.
5. Run the checks above and review the reader before deployment. The collection count, filters, fallback HTML and structured data update automatically.

This phase uses a repository-managed catalogue. It does not include a browser upload/admin CMS, user accounts, full-text search, saved reading positions, or AI querying. For a substantially larger collection, move files to object storage behind a same-origin media route and replace the catalogue with a curated database; preserve the IDs and provenance fields.

## Starter editions

| Work | Edition/source | Format |
| --- | --- | --- |
| Tao Te Ching | James Legge; [Gutenberg 216](https://www.gutenberg.org/ebooks/216) | PDF, original EPUB, original text |
| Meditations | Meric Casaubon; [Gutenberg 2680](https://www.gutenberg.org/ebooks/2680) | PDF, original EPUB, original text |
| The Kybalion | Three Initiates, 1908; [Gutenberg 14209](https://www.gutenberg.org/ebooks/14209) | PDF, original EPUB, original text |

The source publisher identifies these editions as public domain in the USA; the UI does not claim universal public-domain status. The Kybalion is explicitly described as a modern esoteric work. None is presented as a newly discovered or authenticated 'hidden' manuscript.

The PDFs are reflowed reading editions, not scans or critical editions. Source wording and Project Gutenberg notices remain; pagination, typography and line wrapping are new. Original EPUBs/text are preserved unchanged. The source files were obtained on 17 October 2026.

To reproduce the supplied PDFs, download `https://www.gutenberg.org/cache/epub/{sourceId}/pg{sourceId}.txt` and `https://www.gutenberg.org/ebooks/{sourceId}.epub3.images` into a source directory as `{sourceId}.txt` and `{sourceId}.epub`. Install Python `reportlab` and `pypdf` and the DejaVu Serif font, then run:

```sh
python scripts/prepare-reading-editions.py /path/to/source-directory
```

This helper is for the supplied Gutenberg editions, not a general import system. Gutenberg may update source files, so regenerated hashes can differ. Published `provenance.json` records the exact shipped bytes.

## Future source-grounded inquiry

Keep book IDs and source editions immutable. Add separately versioned text extraction with page/section anchors, then a retrieval index. The AI layer should return cited passages linked to those anchors and the original file checksum. Store personal notebooks separately from the public source collection. The current UI describes this phase as in development and never simulates answers.
