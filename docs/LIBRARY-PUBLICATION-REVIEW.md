# Proposed publication of the 391 flagged library files

Status: awaiting explicit confirmation of scope following automatic approval review. No R2 public-access changes have been applied by this request.

## Proposed scope

Make the following 143 source titles public in their 143 PDF and 143 EPUB representations, together with 70 linked overview PDFs and 35 linked overview PPTX files: 391 files in total. The 226 files already public are unchanged.

This proposal follows the user's instruction to make non-duplicate articles publicly available. Approval review interpreted “articles” as narrower than this collection of ebooks and overview decks, so explicit confirmation of the complete scope is required.

## Duplicate check

- The complete approved corpus contains 617 distinct SHA-256 file identities; there are no exact duplicate files.
- None of the 188 source-text records have the same normalized title and author as another source-text record.
- PDF/EPUB representations and separately identified editions are retained as distinct formats or editions.
- Two standalone decks share the title “THE CELESTIAL CODEX”, but they are different contents: presentation 053 concerns the Primal Diet (23 pages), while presentation 241 concerns astrotheology and the Solar Messiah (11 pages). Both were already public and remain unchanged.

The earlier private flags were generated from metadata wording, not a completed copyright review. Most affected titles have the same generic private-collection note. Linked overviews inherited the source-title flag.
